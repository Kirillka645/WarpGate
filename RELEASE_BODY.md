# WarpGate v1.0.2

Исправление сетевых ошибок при регистрации в Cloudflare WARP.

## Что нового

- **Приоритет IPv4 при обращении к API WARP.** На сетях с неисправным IPv6 (типично для мобильного интернета) соединение устанавливалось по IPv6, но TLS-байты терялись — приложение падало с `net/http: TLS handshake timeout`, хотя IPv4 работал отлично. Теперь ядро сначала пробует IPv4-адреса и только потом IPv6.
- **Резервное поколение API.** Регистрация device'а идёт через `v0a2158`, а если этот путь недоступен — через `v0i1909051800` и наоборот. Оба поколения возвращают одинаковые данные (`client_id`, адреса, ключ пира), поэтому блокировка одного из них больше не мешает.
- **Повторы при сетевых сбоях.** Транзиентные обрывы (captive portal, смена вышки сотовой связи, DPI-сброс) теперь автоматически переотправляются с задержкой — до трёх попыток на каждое поколение API.
- **Понятные сообщения об ошибках.** Вместо технического `Post "https://api.cloudflareclient.com/v0a2158/reg": net/http: TLS handshake timeout` приложение теперь пишет, что именно произошло и что делать: «Cloudflare WARP не отвечает — соединение блокируется или зависает. Попробуйте другую сеть или включите VPN». Отдельно различаются DNS-ошибки, отклонение и сброс соединения, отсутствие маршрута и перехват сертификата.

## Возможности

- **WARP-профили** — регистрация устройства в Cloudflare прямо из приложения, ключи не покидают телефон
- **Генератор конфигов** — вкладка «Генератор» собирает готовый `AmneziaWG .conf` или `Clash / Mihomo .yaml` (формат [warp-config-ru](https://github.com/AppsGanin/warp-config-ru)): I1-маски, DNS-обход геоблока, MTU 1280
- **Оптимизатор эндпоинтов** — приложение замеряет пинг реальным WireGuard-хендшейком до 27 эндпоинтов Cloudflare (порты 2408/500/1701/4500) и автоматически выбирает самый быстрый
- **AmneziaWG** — импорт конфигов `.conf` с обфускацией (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1–H4`)
- **MASQUE** — WARP поверх HTTP/3 (экспериментально)
- **Подписки в стиле Happ** — URL-подписки (base64) и ссылки `vless://`, `vmess://`, `ss://`, `trojan://`, `hysteria2://`
- Тёмная тема, русский интерфейс, Material 3 (Jetpack Compose), адаптивная иконка

## Установка

1. Скачайте `WarpGate-v1.0.2-debug.apk` ниже
2. Разрешите установку из неизвестных источников
3. Нажмите «+» → «WARP-профиль» — приложение создаст ключ и выберет лучший эндпоинт
4. При первом подключении разрешите VPN

## Если не создаётся профиль

Если сеть оператора блокирует `api.cloudflareclient.com`, WARP-профиль не зарегистрируется — это ограничение сети, а не приложения. Варианты:

- включить VPN (тогда приложение пойдёт через туннель);
- собрать конфиг во вкладке «Генератор» — там другой формат вывода, и его можно импортировать в AmneziaVPN или Clash.
