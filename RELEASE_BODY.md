# WarpGate v1.0.1

Обновление с генератором WARP-конфигов, собственной иконкой приложения и исправлением нижней навигации.

## Что нового

- **Генератор WARP-конфигов** — новая вкладка «Генератор»: приложение регистрирует новое устройство в Cloudflare WARP и собирает готовый файл `AmneziaWG .conf` или `Clash / Mihomo .yaml`. Формат совпадает с генератором [warp-config-ru](https://github.com/AppsGanin/warp-config-ru): I1-маски AmneziaWG (мимикрия под QUIC/SIP-хендшейк), DNS-резолверы для обхода геоблока, MTU 1280, `Jc=4 / Jmin=40 / Jmax=70`, `H1–H4`. Ключи генерируются на устройстве и наружу не отправляются.
- **Экспорт конфига** — копирование в буфер, отправка в мессенджер через системное меню «Поделиться» и сохранение в «Загрузки» (на Android 10+ без дополнительных разрешений).
- **Выбор эндпоинта** — конкретный хост и порт из пула WARP либо «Авто» (случайный адрес и порт, разброс устойчив к блокировкам отдельных диапазонов).
- **Двухстековый режим** — переключатель IPv6 в конфиге.
- **Нижняя навигация больше не перекрывается системной панелью** — раньше плавающая панель вкладок уходила под системную навигацию, и нижние кнопки не нажимались. Теперь учитываются insets (в том числе при открытой клавиатуре), а точки навигации не меньше 48 dp.
- **Своя иконка приложения** — адаптивная иконка (щит с вырезанной молнией), monochrome-слой для тем оформлений Android 13+ и растровые версии для старых лаунчеров.
- **Исправлен импорт `ss://`-ссылок** вида `base64(method:pass)@host:port` — раньше они не распознавались.

## Возможности

- **WARP-профили** — регистрация устройства в Cloudflare прямо из приложения, ключи не покидают телефон
- **Оптимизатор эндпоинтов** — приложение замеряет пинг реальным WireGuard-хендшейком до 27 эндпоинтов Cloudflare (порты 2408/500/1701/4500) и автоматически выбирает самый быстрый
- **AmneziaWG** — импорт конфигов `.conf` с обфускацией (`Jc`, `Jmin`, `Jmax`, `S1`, `S2`, `H1–H4`)
- **MASQUE** — WARP поверх HTTP/3 (экспериментально)
- **Подписки в стиле Happ** — URL-подписки (base64) и ссылки `vless://`, `vmess://`, `ss://`, `trojan://`, `hysteria2://`
- Тёмная тема, русский интерфейс, Material 3 (Jetpack Compose)

## Установка

1. Скачайте `WarpGate-v1.0.1-debug.apk` ниже
2. Разрешите установку из неизвестных источников
3. Нажмите «+» → «WARP-профиль» — приложение создаст ключ и выберет лучший эндпоинт
4. При первом подключении разрешите VPN

Чтобы получить конфиг для AmneziaVPN или Clash, откройте вкладку «Генератор» → «Сгенерировать конфиг» → «Сохранить» или «Поделиться».
